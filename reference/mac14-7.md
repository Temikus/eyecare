## Notes

- A plain 60 Hz IPS panel with a backlight: no local dimming zones (`IOMFBIsHiloDevice` false), no
  low-framerate compensation, no ambient light sensor statistics support. Expect a mini-LED or
  ProMotion machine to differ substantially.
- None of the seven dimming keys macOS 27 added is published here, and unpublished keys are rejected
  whatever type is written, so on this machine the settable set equals the published set. See
  [../TESTING.md](../TESTING.md) for the evidence and the boot-arg hypothesis.
- `enablePulseWidthMaximization` is published and accepted, and sits at `0`. It predates macOS 27.
- `pwm-frequency` of 24000000 reads like the PWM timer's clock source rather than the backlight
  modulation rate; the panel's `nits-to-pwm-percentage` table maps brightness to duty cycle.
- `IOMFBBrightnessLevelIDAC` and `…MA` both read `-1`, i.e. unset rather than a measurement.
